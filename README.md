# Личные финансы

Терминальное приложение на Java для учёта доходов и расходов, бюджетов по категориям и финансовых отчётов. У каждого пользователя свой кошелёк.

## Сборка и запуск

Понадобятся JDK 17 или новее и Maven. Из корня проекта выполните:

```sh
mvn verify
java -jar target/personal-finance-1.0.0.jar
```

`mvn verify` компилирует проект для Java 17, запускает модульные и интеграционные проверки на стандартной библиотеке Java и создаёт исполняемый JAR. Чтобы запустить только проверки и компиляцию, выполните `mvn test`. При первой сборке Maven загружает плагины. GitHub Actions выполняет `mvn verify` на Temurin 17.

## Первый сеанс

Введите следующие строки в приложении. После `register` и `login` пароль вводится отдельной строкой. Подставьте свой пароль вместо `учебный пароль`.

```text
register anna
учебный пароль
login anna
учебный пароль
income 20000 Зарплата
income 40000 Зарплата
income 3000 Бонус
expense 300 Еда
expense 500 Еда
expense 3000 Развлечения
expense 3000 Коммунальные услуги
expense 1500 Такси
budget 4000 Еда
budget 3000 Развлечения
budget 2500 Коммунальные услуги
report
report Еда, Такси
export-csv Мой кошелёк.csv
exit
```

Общая сводка покажет доход 63 000, расход 8300 и баланс 54 700. По «Еде» остаток составит 3200, по «Развлечениям» — 0, по «Коммунальным услугам» — −500. После перезапуска войдите под тем же логином и выполните `report`, чтобы проверить сохранённое состояние.

В отчёте `report Еда, Такси` строка `Баланс — -2300.00` относится только к выбранным категориям. В них записаны расходы на 800 и 1500, а доходов нет. Команда `balance` покажет баланс всего кошелька — 54 700.

## Команды кошелька

`help` показывает доступные команды и примеры. Логины чувствительны к регистру. Для суммы допустимы точка или запятая и до двух десятичных знаков. Одиночное название категории в конце команды можно вводить с пробелами без кавычек.

| Действие | Команда |
| --- | --- |
| Посмотреть текущий логин или сменить пользователя | `whoami`, `login boris` |
| Выйти из учётной записи или завершить работу | `logout`, `exit` |
| Внести операцию | `income 60000 Зарплата`, `expense 250,50 Коммунальные услуги` |
| Перевести средства другому пользователю | `transfer 250 boris` |
| Посмотреть баланс, историю или категории | `balance`, `history`, `categories` |
| Создать или переименовать категорию | `category Аптека`, `category-rename Еда, Продукты` |
| Установить, изменить или снять лимит | `budget 4000 Еда`, `budget-change 4500 Еда`, `budget-remove Еда` |
| Построить общую сводку или выборку | `report`, `report Еда, Такси` |
| Построить отчёт за период | `report-period 2026-11-01 2026-11-30 Еда, Такси` |
| Сохранить текстовый отчёт | `report-file Еда, Такси`, `report-file-period 2026-11-01 2026-11-30` |
| Выгрузить или восстановить CSV-снимок | `export-csv Мой кошелёк.csv`, `import-csv Мой кошелёк.csv` |

Команды записи операций добавляют новые категории в каталог автоматически. В списках и при переименовании разделяйте названия запятыми. Если название содержит запятую или кавычки, заключите его в двойные кавычки и удвойте внутренние кавычки. Пример команды — `report "Еда, кафе", "Премия ""зима"" за год"`.

Отчёт за период включает обе даты. Отчёты и импорт CSV принимают существующие календарные даты в формате `ГГГГ-ММ-ДД` с годом от `0001` до `9999`. В отчёте за период показывается разница доходов и расходов за выбранные даты. Общий баланс и текущие остатки бюджетов показывает `report`.

### Как сохранить текстовый отчёт

Войдите в кошелёк. Введите команду, нажмите Enter и после запроса введите имя нового файла отдельной строкой.

```text
report-file Еда, Такси
Мой отчёт.txt
```

Файл появится в папке, из которой вы запустили приложение. Для сохранения в другом месте введите полный путь, например `/Users/anna/Desktop/Мой отчёт.txt` (вместо `anna` укажите имя своей учётной записи macOS). Путь с пробелами вводите без кавычек. Папка должна существовать. Последняя часть пути задаёт точное имя файла, включая расширение. Если файл с таким именем уже есть, повторите команду и выберите другое имя.

### Как восстановить кошелёк из CSV

Команда `export-csv Мой кошелёк.csv` создаёт новый файл с категориями, лимитами и операциями. Для CSV путь указывается в той же строке, что и команда. Чтобы проверить восстановление, запустите приложение из той же папки, где прошёл первый сеанс. Зарегистрируйте нового пользователя `boris`, войдите под ним и введите следующие строки.

```text
import-csv Мой кошелёк.csv
yes
balance
```

Введите `yes` после запроса на замену данных текущего кошелька. После успешного импорта у Бориса появится собственная копия с балансом 54 700.

Набор переводов в снимке должен точно совпадать с переводами текущего кошелька по ID, типу операции, сумме, дате, контрагенту и количеству записей. В примере у Анны на момент экспорта и у нового пользователя Бориса переводов нет. Снимок с переводами можно восстановить в кошельке с теми же переводами. Если хотя бы одна запись перевода добавлена, удалена или изменена по указанным полям, приложение отклонит импорт целиком.

### Уведомления

CLI сообщает о превышении бюджета категории и общих расходов над доходами. Дополнительные уведомления появляются при достижении 80% положительного лимита и переходе баланса в ноль. При переводе приложение проверяет эти условия только у отправителя. Получатель увидит зачисление в `history` и обновлённый баланс в `balance`.

## Переводы

Команда `transfer 250 boris` списывает 250 с текущего кошелька и зачисляет их зарегистрированному пользователю `boris`. Получателю не нужно входить в приложение в этом сеансе. Сумма должна быть положительной и укладываться в текущий баланс. Переводы самому себе отклоняются.

Категория «Переводы» закрепляется за переводами при создании. Её можно переименовать ещё до первого перевода, и операции будут использовать новое имя. Привязка сохраняется в файле кошелька и в CSV-снимке. В истории и CSV-снимках сохраняются логин второй стороны и общий идентификатор перевода. Перевод учитывается в сводках и в бюджете категории отправителя, если он установлен.

При выходе связанные кошельки сохраняются через журнал. Если запись одного из файлов прервалась, следующий запуск повторит сохранение из журнала перед открытием CLI. Если запись всё ещё недоступна, приложение сообщит об ошибке и сохранит журнал для следующей попытки.

## Хранение и архитектура

Приложение хранит учётные записи и кошельки в `.finance-data` относительно рабочего каталога запуска. Используйте тот же рабочий каталог для доступа к ранее сохранённым данным. Учётные записи записываются при регистрации и содержат солёные хеши паролей. Кошельки загружаются при входе, изменяются в памяти и сохраняются по `exit` или при закрытии входного потока. Приложение блокирует каталог данных на время работы.

| Пакет | Ответственность |
| --- | --- |
| `finance.model` | Операции, кошельки, категории, денежные суммы и бюджеты |
| `finance.service` | Авторизация, операции с кошельком, статистика, оповещения и интерфейсы хранилищ |
| `finance.infrastructure` | Файловые хранилища, разбор и запись CSV |
| `finance.cli` | Разбор команд, справка и форматирование вывода |
| `finance.Main` | Создание сервисов, подключение хранилищ и жизненный цикл приложения |

Проверки в `src/test/java` используют отдельные временные каталоги для интеграционных сценариев. Итоговый счётчик в выводе Maven показывает число пройденных сценариев и ошибок.
